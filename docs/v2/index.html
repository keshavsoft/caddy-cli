Version 2 Flagship Specification

v2: Upstream Ports & Route Inspector

Transforms caddy-cli into a full reverse proxy observability tool by resolving backend dial targets, mapping occupied ports, and inspecting individual subdomain configurations.

Recursive Subroute Parsing

Traverses Caddy's handle → subroute → routes → handle trees to extract reverse_proxy upstreams and file_server roots.

Port & Dial Target Mapping

Instantly answers "Which domain is on port 3001?" or "Is port 9012 already taken?" with the dedicated -p / --ports flag.

Subdomain Configuration Drill-down

Inspect only a single subdomain's configuration block without sifting through a massive 300-line JSON document via -d <domain>.

Raw JSON Output (--json)

Outputs structured JSON for direct piping into jq, automation scripts, or deployment pipelines.

V2 CLI Commands & Options

# 1. Default: View all domains, upstream ports, and match paths:
npx caddy-cli
# 2. View port & dial target mappings:
npx caddy-cli -p
# 3. Inspect a specific subdomain configuration:
npx caddy-cli -d quotation.keshavsoft.com
# 4. Extract raw route JSON for a subdomain:
npx caddy-cli cc9.keshavsoft.com --json

V2 Programmatic API 

import {
  inspectRoutes,
  inspectRoutesFromFile,
  getPortMappings,
  getPortMappingsFromFile,
  findRouteByHost,
  findRouteByHostFromFile
} from "caddy-cli";

// Inspect all routes & reverse proxy dials:
const routes = inspectRoutesFromFile("./caddy.json");

// Map all backend ports:
const ports = getPortMappingsFromFile("./caddy.json");

// Find route for specific domain:
const match = findRouteByHostFromFile("./caddy.json", "cc9.keshavsoft.com");
console.log(match.rawRoute);
