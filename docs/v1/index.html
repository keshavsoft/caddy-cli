Version 1 Specification

v1: Hostname & JSONPath Extractor

The genesis version designed to rapidly extract all declared hostnames and their structural JSON paths from Caddy JSON files.

Purpose & Design Goals

In Caddy, every route matching block encapsulates host declarations inside match[].host[] arrays. V1 established the foundation by employing jsonpathly to search the entire document tree using the expression:

$..host[*]

This yields both the raw string array of hostnames and their full JSON traversal path (e.g. $['apps']['http']['servers']['srv0']['routes'][0]['match'][0]['host'][0]).

V1 CLI Usage

# Print table of hostnames and their JSON paths:
npx caddy-cli
# Print only unique hostnames:
npx caddy-cli -u
# Output as JSON array:
npx caddy-cli --json

V1 Programmatic API 

import { extractHosts, extractHostsFromFile } from "caddy-cli/v1";

// From file:
const { hosts, hostPaths, uniqueHosts, tableData } = extractHostsFromFile("./caddy.json");

// From in-memory object:
const res = extractHosts(caddyConfig);
console.log(res.uniqueHosts);
